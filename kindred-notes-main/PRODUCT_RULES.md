# Product Rules — Memoir (Private Collaborative Diary)

## Non-Negotiable Rules

1. **All accounts are private by default** — No public discovery, no suggested users.
2. **Collaboration only by mutual consent** — Both parties must agree before any shared access.
3. **Memories are immutable history** — Edits are tracked, nothing is silently overwritten.
4. **Emotional safety > virality** — No dark-pattern gamification, no engagement bait.
5. **No public profile URLs** — User IDs are not searchable by default; exact match only.
6. **Block overrides everything** — A blocked user has zero visibility.
7. **AI is a gentle assistant, not a therapist** — No mental health diagnosis, no memory rewriting, no training on user data.
8. **User data belongs to the user** — Data export and account deletion are always available.
9. **Privacy by design** — EXIF stripped from images, no public image URLs, end-to-end encryption planned.
10. **Calm UX** — Slow interactions, no infinite dopamine loops, human-centered design.
